# Agent logo cutouts

Created with the built-in ImageGen editing tool, with transparent background enabled. Each PNG was checked for a real alpha channel before integration.

## claude-code

Saved asset: public/claude-code-agent-logo.png

Prompt:

Use case: background-extraction. Edit target: the attached claude-code agent logo. Remove its exterior square/app-tile background entirely and return a genuine transparent PNG cutout of the logo symbol only. Preserve the original mark geometry, colors, gradients, angle and proportions exactly. Do not redesign or add any elements. Remove white backdrop and make negative-space holes transparent as well. Keep original square framing and symbol scale, no shadow or checkerboard background.
